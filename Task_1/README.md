# Task 1 – Embedded Systems & IoT

This task covers:

1. Introduction to Embedded Systems
2. Component Study – Microcontrollers and Sensors
3. Mini Project – Smart Temperature Monitoring and Alert System

The mini project was designed and simulated using Arduino UNO,
TMP36 temperature sensor, LED and buzzer in Tinkercad Circuits.
